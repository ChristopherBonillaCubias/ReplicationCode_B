## Employment Automation Copilot MVP

This repository now includes a buildable product blueprint for an assisted employment automation SaaS aimed at international students seeking part-time work in Australia. The MVP design uses agentic workflow steps with a human-in-the-loop **Approve & Send** gate rather than blind mass submission.

- Blueprint: [`docs/employment-automation-copilot-mvp.md`](docs/employment-automation-copilot-mvp.md)
- Core workflow: `Input → Parse → Verify → Match → Generate → Review → Approve → Submit/Assist → Track → Learn`
- MVP promise: “Apply to 20 high-fit jobs in 30 minutes, not 200 random jobs in 20 hours.”
